Branding & hosts

Branding and hostnames are driven by GitHub Actions variables (and matching Cloud Run / Secret Manager env). Do not commit customer logos or secrets into source.

VariableUsed forExample
APP_NAMEProduct name in chrome / emailsCustomer brand name
PRIMARY_COLORAccent / CSS brand token#2563eb
LOGO_URLNav / loginHTTPS URL
CUSTOM_DOMAINProd web host / cookiesapp.{apex}
DEV_CUSTOM_DOMAINDev web hostdev.{apex}
PROD_WEB_BASE_URLAbsolute prod web URLhttps://app.{apex}
DEV_WEB_BASE_URLAbsolute dev web URLhttps://dev.{apex}
PROD_API_BASE_URLBaked into prod web as VITE_API_URLhttps://api.{apex}
DEV_API_BASE_URLBaked into dev web as VITE_API_URLhttps://dev-api.{apex}

Critical: tenant API, not shared API

Do not point the SPA at https://api.serviceflow-pro.com. Tenant login must use api.{apex} with CORS configured on the tenant API during domain setup. Missing or wrong bake → CORS failures. Fix Actions variables, then re-run Deploy Prod / Deploy Dev.
