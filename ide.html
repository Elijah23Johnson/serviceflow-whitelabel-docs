ServiceFlow Pro IDE

Optional local path for white-label tenants. Complements AI Change Studio (cloud agents).

What it is

A branded VS Code OSS build that:

  1. Signs in with device auth against AI Change Platform.
  2. Clones the business’s private serviceflow-wl-* repo.
  3. Writes a local .env from the bootstrap/env bundle.
  4. Runs API + Web via committed .vscode launch/tasks.

Customer flow

  1. ServiceFlow → Settings → Integrations → White-label AI Change → Download ServiceFlow Pro IDE (or Open in IDE).
  2. Install for your platform (macOS arm64/x64, Windows).
  3. Sign in from the IDE sidebar; approve the device code in the browser.
  4. Run ServiceFlow: Open My Code, then Run and Debug → API + Web.

Installers resolve via ServiceFlow API /api/white-label-ai-change/ide-download (GCS bucket default serviceflow-pro-ide-downloads).
