ServiceFlow White-Label Docs

Public documentation for White-label Light (White-label AI Change). Template source code stays private.

When a business activates White-label AI Change in ServiceFlow (Settings → Integrations):

  1. AI Change Platform generates a private tenant repo from the curated template (serviceflow-wl-{slug}).
  2. Collaborator emails are invited under the platform GitHub account.
  3. Domain setup maps four hosts — app. / dev. (web) and api. / dev-api. (API) — and configures tenant CORS.
  4. develop deploys to dev; master deploys to prod.
  5. Ship changes via AI Change Studio or locally with ServiceFlow Pro IDE.
